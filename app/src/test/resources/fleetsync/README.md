# FleetSync real-air fixtures

Two 1.3 s slices of real Kenwood transmissions (Fleet 107 / Unit 1772, 462.5625 MHz), one FleetSync I and one
FleetSync II, channelized to 48 kHz complex baseband, headerless interleaved int16 I/Q (little-endian).

From GopherTrunk by Matt Cheramie, `internal/radio/fleetsync/afsk/testdata`, Apache License 2.0
(https://github.com/MattCheramie/GopherTrunk). The captures were contributed by @v2maldo on GopherTrunk issue #1184.
Used unchanged, as test data only.
